# Built-in word tables

`ffta-decomp-v4.1.tsv` is derived from the public **FFTA-DECOMP /
FFTA2-US-CHS V4.1** charset:

- Source: https://github.com/ffta-decomp/FFTA-US-CHS/tree/main/charset/v4.1
- Upstream files: `glyphs.json`, `decode.tbl`, `glyphs.csv`
- License: GNU GPL v3 (see `GPL-3.0.txt`)
- Scope: game-code -> Unicode/glyph-label mapping only. No ROM, font pixels,
  translations or other game assets are included.

The TSV is generated by taking each `game_code_hex` and its `character`
(or `glyph_label` when the glyph is a named native symbol), preserving the
upstream ordering and duplicate aliases.
