# Web UI 中文显示

在工具栏选择“简体中文”，可切换编辑器标签及选项。语言选择会保存在浏览器中。

- 补充 130 个字段标签、262 个枚举标签，以及已知装备、职业、种族和地区标志位说明。
- 职业、技能、技能组、道具、角色、任务、法则、合成分类、地区和地点共有 2,987 个名称译法。匹配时显示“中文名（原文）”，支持按中文、英文或编号检索。
- 名称按类别及完整英文名匹配；已有中文及未匹配的自定义名称保持原样。12 个一名多译的英文名暂不自动匹配。
- 未知值保留原始编号；含义未确认的选项标为“推测”或“待确认”。悬停字段及枚举选项可查看原始标识。

界面翻译只影响显示，不会替换 ROM 文本，也不会改变引用编号、字段标识或标志位顺序。文本编辑器中的内容仍是 ROM 的实际文本。

译名参考 FFTA2 中文汉化项目的 V4.1 后续订正数据。生成文件记录名称来源版本及校验值，只包含名称对照，不包含对白、说明文本、字模或 ROM 数据。前端运行及构建无需访问来源项目。

## 本地检查

`npm run build` 通过。无本地 ROM 夹具时，`npm test` 为 316 项通过、52 项跳过。另以美版 ROM 完成 12 项 UI／i18n 检查，包括全部页签中英文 DOM 渲染、语言切换、名称保持和标志位编辑。

部分既有集成测试要求特定汉化 ROM 或 Java 参考输出，不能使用任意原版 ROM 替代其夹具。实际浏览器截图和像素布局尚未验收。
